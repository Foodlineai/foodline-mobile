Phase 0 — screen designs

The six screens that close the open flows, drawn against the shipped palette and the existing @/components/ui vocabulary — Screen, Group, ListRow, StatusPill, StaleBanner, NoticeCard. Nothing here needs a new primitive.

Each one carries its verified RPC. Where the backend turned out to have a capability we hadn't designed for — catch-weight capture, reversible pick events, count leases — the screen reflects it rather than ignoring it.
